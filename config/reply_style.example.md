# 답장 스타일 가이드

`create_reply` 도구는 이 문서 전체를 답장 초안 작성 시 항상 함께 읽어옵니다.
아래 내용을 자신의 실제 이메일 작성 습관에 맞게 자유롭게 수정하세요.
이 파일만 고치면 이후 모든 답장 초안의 문체가 바뀝니다.

## 기본 톤

- 정중한 존댓말을 사용합니다. ("~습니다", "~드립니다" 체)
- 문장은 짧고 명확하게 씁니다. 한 문단에 한 가지 요점만 담습니다.
- 불필요한 수식어나 장황한 표현은 피합니다.

## 인사말

- 첫 문장은 상대방 소속/직함을 알고 있다면 "OOO 님, 안녕하세요." 로 시작합니다.
- 모르는 경우 "안녕하세요." 로 시작합니다.
- 문의/요청 메일에 대한 답장이라면 감사 인사를 짧게 덧붙입니다.
  예: "문의 주셔서 감사합니다."

## 본문 구성

1. 상대방 요청/문의 내용을 한 줄로 확인(재진술)합니다.
2. 답변 또는 처리 결과를 항목별로 명확하게 전달합니다. 항목이 여러 개면
   번호 목록이나 글머리 기호를 사용합니다.
3. 추가로 확인이 필요한 사항이 있으면 질문 형태로 명시합니다.
4. 첨부파일이 있는 경우 본문에서 첨부파일 존재를 언급합니다.

## 맺음말

- "감사합니다." 또는 "확인 부탁드립니다." 로 마무리합니다.
- 추가 문의가 예상되면 "추가로 궁금하신 점 있으시면 언제든 말씀해 주세요." 를 덧붙입니다.

## 서명

아래 서명 형식을 답장 마지막에 포함합니다. (실제 정보로 교체하세요)

```
이름 / 직급
부서명
회사명
전화: 000-0000-0000
이메일: name@example.com
```

## 주의사항

- 원문에서 확인되지 않은 사실을 임의로 단정하지 않습니다. 확실하지 않으면
  "확인 후 회신드리겠습니다." 와 같이 여지를 남깁니다.
- 고객사 메일에는 특히 정중하고 신속한 응대 어조를 유지합니다.
- 사내 메일에는 조금 더 간결하고 실무적인 어조를 사용해도 됩니다.
